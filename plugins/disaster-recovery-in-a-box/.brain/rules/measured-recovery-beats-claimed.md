THE RULE

Recovery capability is reported as measured values from exercises (achieved RTO and RPO, date, scope, what was simulated), never as the design target. A target never met in a test is a gap, not a status.

- Report achieved and target side by side.
- A tabletop proves the plan is understood, not that the system recovers; say which kind of exercise produced the number.
- Failed or partial tests are kept and reported, with the cause and the fix.

WHY

A plan that has never recovered anything is a hypothesis. Presenting the target as the capability is how organisations learn the truth during a real incident.

HOW TO APPLY

Every DR statement carries: exercise type, date, achieved numbers, deviations. Without an exercise, write "not tested".

EXCEPTIONS

None.

JUDGED AGAINST

Every capability claim shows a measured value or the words "not tested".
