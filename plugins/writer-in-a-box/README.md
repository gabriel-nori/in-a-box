# writer-in-a-box

Role: **Writer**. Accountable for text in a defined tone, handed to other roles as structured artifacts.

Skills: [`tone-of-voice`](skills/tone-of-voice/SKILL.md) produces `tone-guide`; [`post-writer`](skills/post-writer/SKILL.md) produces `post-copy`; [`carousel-writer`](skills/carousel-writer/SKILL.md) produces `post-script`, which `post-designer` in `designer-in-a-box` turns into art.

Planned: `copy-editor`, `headline-writer`, `long-form-writer`. A "complete post" (text plus images) is a flow for `orchestrator-in-a-box`, not a skill: `tone-of-voice`, then `carousel-writer` and `post-writer`, then `post-designer`, `image-generator` (optional), `art-renderer` and `design-reviewer`, with the publish step gated by `marketer`.
