## Purpose

- `infra-ansible`: Defines, changes and reviews host and application configuration as Ansible code (playbooks, roles, collections, inventories), checked in dry-run before it touches a host.
- `infra-cloudformation`: Defines, changes and reviews AWS infrastructure as CloudFormation templates (or SAM/CDK output), with a change set reviewed before any stack update.
- `infra-engineer`: Delivers making sure software has an environment it can run, deploy and be observed in, reproducibly.
- `infra-pulumi`: Defines, changes and reviews infrastructure as Pulumi programs in a general-purpose language, with a previewed change set before any update and secrets kept in the stack config.
- `infra-puppet`: Defines, changes and reviews host configuration as Puppet code (manifests, modules, Hiera data), tested and rolled out in noop first.
- `infra-terraform`: Defines, changes and reviews cloud infrastructure as Terraform or OpenTofu code, with a reviewed plan before any apply and state handled safely.
