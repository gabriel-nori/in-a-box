THE RULE

Organise documentation around the four user needs so each page does one job.

What must be true at the end:
- Documentation sorted into tutorials, how-to guides, technical reference and explanation.

How it is handled:
- Identify which of the four needs a page serves and keep it to that need.
- The framework relates the four forms systematically and organises documentation around those needs.

WHY

Trigger: A feature ships, or a documentation set is written or reorganised.

Inputs:
- The product, its users and what they are trying to do.

HOW TO APPLY

Participants: The documenter and the subject experts.

Expectations of the position:
- **Documenter:** decides the form before writing.
