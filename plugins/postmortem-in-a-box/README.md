# postmortem-in-a-box

Postmortem as a role, because it applies to more than outages: an escaped bug, a vulnerability, an attack.

Skills: [`postmortem-author`](skills/postmortem-author/SKILL.md) (the base contract), [`postmortem-defect`](skills/postmortem-defect/SKILL.md) (escape analysis for a defect), [`postmortem-security`](skills/postmortem-security/SKILL.md) (exposure and control analysis for a vulnerability or attack, with sensitive detail handled for the audience).

Process: [`blameless-postmortem`](processes/blameless-postmortem.md), the one place where order matters (record, draft, review, actions, sharing).
