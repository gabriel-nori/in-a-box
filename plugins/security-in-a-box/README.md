# security-in-a-box

Roles: **Security Reviewer** and **Threat Modeler**.

- [`security-reviewer`](skills/security-reviewer/SKILL.md): finds and ranks security risk in a design or change and says what would close each risk. Produces `threat-notes`.
- [`threat-modeler`](skills/threat-modeler/SKILL.md): builds the threat model of a system or feature. Produces `threat-model`.

Process: [`threat-modeling`](processes/threat-modeling.md), where the four questions build on each other. Secure development practice is a brain rule.
