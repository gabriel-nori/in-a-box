THE RULE

Run work as a visible flow with limited work in progress, and improve the flow from what its measures show.

What must be true at the end:
- Work that is pulled only when there is capacity, aged items that are unblocked, and an improving workflow definition.

How it is handled:
- Make the workflow visible and agree its definition.
- Actively manage items: control the count in progress, prevent unnecessary aging against the service level expectation, unblock stalled work, pull new work only when capacity exists.
- Improve the workflow continuously, changing its definition when the data says to, not on a fixed schedule.
- Measure WIP, throughput, work item age and cycle time.

WHY

Trigger: Continuously, wherever work is managed on a Kanban system.

Inputs:
- A defined workflow: item types, start and finish points, states, WIP limits, explicit policies and a service level expectation.
- The four flow measures.

HOW TO APPLY

Participants: Everyone who takes part in delivering the work, and the stakeholders who depend on it.

Expectations of the position:
- **Everyone:** the Kanban Guide defines no roles, only system members and stakeholders; accountability for flow is shared.

RELATED
