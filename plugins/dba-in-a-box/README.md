# dba-in-a-box

Database administration for SQL work: query, schema, index and migration review with evidence, rollout and rollback.

| Skill | Role | Produces |
|---|---|---|
| [`dba`](skills/dba/SKILL.md) | Base: engine-neutral review | `query-review` |
| [`dba-postgres`](skills/dba-postgres/SKILL.md) | Specialist: PostgreSQL | `query-review` |
| [`dba-mysql`](skills/dba-mysql/SKILL.md) | Specialist: MySQL and MariaDB | `query-review` |
| [`dba-sqlserver`](skills/dba-sqlserver/SKILL.md) | Specialist: SQL Server | `query-review` |

`developer` and its specialists (notably `developer-sql`) consult `dba` before a query or migration ships.
