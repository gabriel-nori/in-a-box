## Purpose

- `security-reviewer`: Delivers finding and ranking security risk in a design or change, and saying what would close each risk.
- `threat-modeler`: Builds a threat model of a system or feature: what it is, what can go wrong, what will be done about each threat and how the team will know the answers hold.
